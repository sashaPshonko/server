# Друг не заходит по Wi‑Fi (no route to host)

Это **роутер режет связь** между устройствами, не Minecraft.

## Быстрый обход — playit.gg (5 минут)

1. На Mac с сервером: https://playit.gg → скачай агент для macOS.
2. Запусти playit, залогинься, создай туннель **Minecraft Java** → порт **25565**.
3. Playit даст адрес вида `something.playit.gg` — **его** друг вводит в «Прямое подключение».
4. Сервер `./start.sh` должен быть запущен.

Работает из любой сети, роутер не трогаем.

## Если хочешь починить Wi‑Fi

1. Зайди в роутер: http://192.168.0.1 (логин на наклейке).
2. Wi‑Fi → выключи **«Изоляция клиентов» / AP isolation / Guest network**.
3. Оба ПК в **одной** сети (не гостевая).
4. На втором ПК: `ping 192.168.0.85` — должен отвечать.
5. IP друга тоже должен быть **192.168.0.XXX** (не 192.168.1.x).

## Тест без роутера

Раздай интернет с **айфона** (точка доступа), подключи оба Mac/ПК к ней, снова `192.168.x.x` из `./connect-info.sh`.
