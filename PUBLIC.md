# Сервер в интернет (кто угодно может зайти)

Локальный IP (`192.168.0.85`) работает только в твоей Wi‑Fi. Для друзей из другой сети / города нужен **публичный адрес**.

## Способ 1 — playit.gg (рекомендуется, без роутера)

1. Запусти Minecraft-сервер:
   ```bash
   cd server && ./start.sh
   ```
2. Скачай агент: https://playit.gg/download (macOS).
3. Установи, войди в аккаунт (бесплатно).
4. **Add tunnel** → тип **Minecraft Java** → локальный порт **25565**.
5. Playit покажет адрес, например:
   ```text
   xyz-abc.gl.joinmc.link
   ```
   или `something.playit.gg` — **это и есть адрес для друзей**.

6. Друг: **Сетевая игра → Прямое подключение** → вставить **только этот адрес** (не `192.168.0.85`).
7. Версия клиента: **Java 1.21.4**.

Пока сервер и playit запущены — зайти может любой, у кого есть адрес.

---

## Способ 2 — проброс порта на роутере

1. Mac с сервером в Wi‑Fi, IP не меняется (лучше зарезервировать `192.168.0.85` в роутере).
2. Роутер http://192.168.0.1 → **Port Forwarding** / «Виртуальные серверы»:
   - внешний порт **25565**
   - внутренний IP **192.168.0.85**, порт **25565**, TCP
3. Узнай внешний IP: https://ifconfig.me или в роутере «WAN IP».
4. Друзья подключаются к **внешнему IP** (не к 192.168.x.x).

Минусы: IP может меняться, провайдер может блокировать 25565, настройка сложнее.

## Безопасность (если сервер «для всех»)

Сейчас `online-mode=false` — любой может зайти под чужим ником.

Для открытого сервера лучше:

1. В `server.properties`:
   ```properties
   white-list=true
   enforce-whitelist=true
   ```
2. В консоли сервера для каждого друга:
   ```text
   whitelist add НикДруга
   ```
3. Или поставить `online-mode=true` (только лицензия Mojang).

## VPS (когда вырастет)

Тот же `paper.jar`, `world/`, `plugins/` на арендованном сервере (Linux) — адрес = IP VPS, порт 25565. См. README «Перенос на VPS».
