# playit на Mac (5 минут)

## 1. Minecraft-сервер

В одном терминале (оставить открытым):

```bash
cd server
./start.sh
```

Дождись `Done! For help, type "help"`.

## 2. playit

1. Открой: https://playit.gg/download  
2. Скачай **macOS** → установи (перетащи в Programs).  
3. Запусти **playit** → войди или **Sign Up** (бесплатно).  
4. **Add tunnel** / «Добавить туннель»:
   - Тип: **Minecraft Java**
   - Локальный адрес: `127.0.0.1` или `localhost`
   - Порт: **25565**
5. Скопируй **публичный адрес** (например `abc-xyz.gl.joinmc.link`).

## 3. Друг подключается

- **Сетевая игра → Прямое подключение**
- Вставить **только адрес playit** (не `192.168.0.85`)
- Версия **Java 1.21.4**

## 4. Проверка

Пока друг заходит — в консоли `./start.sh` должна появиться строка:

```text
НикДруга[/....] logged in
```

---

**Важно:** работают **оба** — и `./start.sh`, и playit. Закрыл playit — друзья не зайдут.

**Аккаунты:** `online-mode=false` — каждый со своим ником, паролей нет.
